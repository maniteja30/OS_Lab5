# OS Lab 5

Operating Systems Lab 5: Image Sharpening Pipeline

This repository contains the implementations, correctness tests,
performance measurements, and report for OS Lab 5.

## Parts

- Part I: Sequential baseline
- Part II.1: Thread-based pipeline
- Part II.2: Process-based pipeline using pipes/FIFOs
- Part II.3: Shared-memory implementation with semaphores
- Part III: Socket-based implementation across two computers
